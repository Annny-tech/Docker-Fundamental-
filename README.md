# 📖 About

This repository documents my Docker learning journey from beginner to advanced concepts.

Instead of simply collecting notes, every topic contains practical examples, commands, exercises, and mini labs to understand how Docker works in real-world DevOps environments.

The goal of this repository is to build a strong foundation before moving into:

- Docker Projects
- Kubernetes
- CI/CD Pipelines
- Cloud Deployments
- DevOps Automation
