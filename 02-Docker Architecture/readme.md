# Docker Architecture

While learning Docker, I realized that simply using Docker commands isn't enough. To truly understand how Docker works, it's important to know what happens behind the scenes whenever we build an image or run a container.

In this section, I explored Docker's architecture by reading documentation, articles, and other learning resources. I documented my understanding here in simple language so I can revisit these concepts whenever needed.

- What Docker Architecture is
- How Docker Engine works
- The role of Docker Client (CLI)
- What Docker Daemon does
- How Docker Registry stores images
- The complete Docker workflow from building an image to running a container
